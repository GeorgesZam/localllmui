# Code Execution Sandbox Skill

## Description
Securely executes Python code generated by the LLM in an isolated sandbox environment. Provides real-time code execution with resource limits and security constraints.

## Use Cases
- Execute code generated by the LLM
- Test data analysis algorithms
- Run data transformations
- Perform mathematical computations
- Visualize data with matplotlib
- Debug and iterate on code

## Architecture Integration

The sandbox sits between the LLM output and UI display:

```
LLM → Code Detection → Sandbox → Results → UI
```

## Implementation

```python
import subprocess
import signal
import resource
import tempfile
import os
import sys
from pathlib import Path
from typing import Dict, Any, Optional
import ast

class SandboxResult:
    """Result of code execution"""
    def __init__(self, success: bool, output: str = "", error: str = "",
                 execution_time: float = 0, return_code: int = None):
        self.success = success
        self.output = output
        self.error = error
        self.execution_time = execution_time
        self.return_code = return_code

class CodeSandbox:
    """Secure code execution sandbox"""

    # Blocked operations for security
    BLOCKED_PATTERNS = [
        'import os', 'import sys', 'import subprocess',
        'import socket', 'import urllib', 'import requests',
        '__import__', 'eval(', 'exec(', 'compile(',
        'open(', 'file(', 'input(', 'raw_input('
    ]

    # Allowed modules for data science
    ALLOWED_MODULES = [
        'math', 'random', 'datetime', 'json', 're',
        'collections', 'itertools', 'statistics',
        'fractions', 'decimal', 'string', 'textwrap'
    ]

    def __init__(self,
                 timeout: int = 30,
                 memory_limit_mb: int = 256,
                 max_output_length: int = 10000):
        self.timeout = timeout
        self.memory_limit = memory_limit_mb * 1024 * 1024  # Convert to bytes
        self.max_output_length = max_output_length
        self.temp_dir = tempfile.mkdtemp(prefix="localllm_sandbox_")

    def execute(self, code: str, context: Optional[Dict[str, Any]] = None) -> SandboxResult:
        """
        Execute code in isolated sandbox

        Args:
            code: Python code to execute
            context: Optional variables to inject into execution

        Returns:
            SandboxResult with execution details
        """
        import time
        start_time = time.time()

        # Validate code first
        validation_error = self._validate_code(code)
        if validation_error:
            return SandboxResult(
                success=False,
                error=f"Code validation failed: {validation_error}",
                execution_time=time.time() - start_time
            )

        # Prepare execution
        exec_script = self._prepare_execution_script(code, context)

        try:
            # Execute in subprocess with resource limits
            result = subprocess.run(
                [sys.executable, '-c', exec_script],
                capture_output=True,
                text=True,
                timeout=self.timeout,
                cwd=self.temp_dir,
                env=self._get_restricted_env()
            )

            execution_time = time.time() - start_time

            # Process output
            output = result.stdout[-self.max_output_length:] if result.stdout else ""
            error = result.stderr[-self.max_output_length:] if result.stderr else ""

            return SandboxResult(
                success=result.returncode == 0,
                output=output,
                error=error,
                execution_time=execution_time,
                return_code=result.returncode
            )

        except subprocess.TimeoutExpired:
            return SandboxResult(
                success=False,
                error=f"Execution timeout (> {self.timeout}s)",
                execution_time=self.timeout
            )
        except Exception as e:
            return SandboxResult(
                success=False,
                error=f"Sandbox error: {str(e)}",
                execution_time=time.time() - start_time
            )

    def _validate_code(self, code: str) -> Optional[str]:
        """Validate code for security issues"""
        try:
            # Parse AST
            tree = ast.parse(code)

            # Check for dangerous imports
            for node in ast.walk(tree):
                if isinstance(node, ast.Import):
                    for alias in node.names:
                        if alias.name not in self.ALLOWED_MODULES:
                            return f"Module '{alias.name}' is not allowed"
                elif isinstance(node, ast.ImportFrom):
                    if node.module not in self.ALLOWED_MODULES:
                        return f"Module '{node.module}' is not allowed"
                elif isinstance(node, ast.Call):
                    # Check for dangerous function calls
                    if isinstance(node.func, ast.Name):
                        if node.func.id in ['eval', 'exec', 'compile']:
                            return f"Function '{node.func.id}' is not allowed"

            # Check for blocked patterns
            code_lower = code.lower()
            for pattern in self.BLOCKED_PATTERNS:
                if pattern in code_lower:
                    return f"Pattern '{pattern}' is not allowed"

            return None

        except SyntaxError as e:
            return f"Syntax error: {str(e)}"

    def _prepare_execution_script(self, code: str, context: Optional[Dict[str, Any]]) -> str:
        """Prepare the execution script with context and output capture"""
        script = f"""
import sys
from io import StringIO

# Capture stdout
old_stdout = sys.stdout
sys.stdout = captured_output = StringIO()

"""

        # Add context variables
        if context:
            for key, value in context.items():
                script += f"{key} = {repr(value)}\n"

        # Add user code
        script += f"""
# User code
try:
{self._indent_code(code)}
except Exception as e:
    print(f"Error: {{e}}", file=sys.stderr)

# Restore stdout
output = captured_output.getvalue()
sys.stdout = old_stdout
print(output, end='')
"""
        return script

    def _indent_code(self, code: str) -> str:
        """Indent code for execution"""
        lines = code.split('\n')
        return '\n'.join('    ' + line if line.strip() else line for line in lines)

    def _get_restricted_env(self) -> Dict[str, str]:
        """Get restricted environment for subprocess"""
        env = {
            'PATH': '/usr/bin:/bin',
            'PYTHONPATH': '',
            'HOME': self.temp_dir,
            'TMPDIR': self.temp_dir,
            'PYTHONDONTWRITEBYTECODE': '1',
        }
        return env

    def cleanup(self):
        """Clean up temporary files"""
        import shutil
        try:
            shutil.rmtree(self.temp_dir, ignore_errors=True)
        except Exception:
            pass

    def __del__(self):
        self.cleanup()


# Integration with LLM
class CodeExecutionSkill:
    """Skill for executing code from LLM responses"""

    def __init__(self):
        self.sandbox = CodeSandbox()

    def extract_and_execute(self, llm_response: str) -> tuple[str, str]:
        """
        Extract code blocks from LLM response and execute

        Returns:
            tuple: (updated_response, execution_results)
        """
        import re

        # Find Python code blocks
        pattern = r'```python\n(.*?)\n```'
        matches = re.findall(pattern, llm_response, re.DOTALL)

        if not matches:
            return llm_response, ""

        results = []
        for i, code in enumerate(matches):
            result = self.sandbox.execute(code)

            if result.success:
                result_text = f"✓ Execution successful ({result.execution_time:.2f}s)\n"
                if result.output:
                    result_text += f"Output:\n{result.output}"
                else:
                    result_text += "(no output)"
            else:
                result_text = f"✗ Execution failed\n"
                if result.error:
                    result_text += f"Error: {result.error}"

            results.append(f"**Code Block {i+1}:**\n{result_text}")

        # Insert results after code blocks
        updated_response = llm_response
        for i, match in enumerate(matches):
            placeholder = f"<!-- EXECUTION_RESULT_{i} -->"
            updated_response = updated_response.replace(
                f"```python\n{match}\n```",
                f"```python\n{match}\n```\n\n{results[i]}\n\n{placeholder}",
                1
            )

        return updated_response, "\n\n---\n\n".join(results)

    def __del__(self):
        if hasattr(self, 'sandbox'):
            self.sandbox.cleanup()
```

## Parameters

- `timeout`: Maximum execution time in seconds (default: 30)
- `memory_limit_mb`: Memory limit in MB (default: 256)
- `max_output_length`: Maximum output characters (default: 10000)
- `allowed_modules`: List of allowed import modules
- `blocked_patterns`: List of blocked code patterns

## Returns

`SandboxResult` object containing:
- `success`: Boolean indicating if execution succeeded
- `output`: Standard output from execution
- `error`: Error message if failed
- `execution_time`: Time taken to execute
- `return_code`: Process return code

## Security Features

1. **Code Validation**: AST parsing to detect dangerous operations
2. **Module Whitelisting**: Only allow safe modules
3. **Pattern Blocking**: Block dangerous functions
4. **Process Isolation**: Execute in separate subprocess
5. **Resource Limits**: Timeout and memory restrictions
6. **Environment Restrictions**: Limited environment variables
7. **Temporary Directory**: Isolated file system access

## Integration Example

```python
# In LLM engine (llm.py)
from sandbox import CodeExecutionSkill

class LLMEngine:
    def __init__(self):
        # ... existing init ...
        self.code_skill = CodeExecutionSkill()

    def generate(self, message: str) -> Iterator[str]:
        # ... existing generation ...

        full_response = ""

        for chunk in self.llm(...):
            token = chunk["choices"][0]["text"]
            full_response += token
            yield token

        # After generation complete
        updated_response, exec_results = self.code_skill.extract_and_execute(full_response)

        if exec_results:
            # Yield execution results
            yield f"\n\n--- Execution Results ---\n{exec_results}"
```

## Error Handling

- Syntax errors are caught during validation
- Runtime errors are caught and displayed
- Timeouts prevent infinite loops
- Memory limits prevent excessive usage
- All errors are formatted for user display

## Performance Considerations

- Execution happens in separate process (non-blocking)
- Timeout prevents hanging
- Output truncation prevents memory issues
- Cleanup ensures no resource leaks
